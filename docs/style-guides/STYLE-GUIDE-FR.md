# Style guide: FR (French) blog posts

Inherits `../02-STYLE-GUIDE-MASTER.md`. Sources: dlvibe `STYLE-GUIDE-FR.md` plus the
client's FR content guidelines (banned phrases, CSS, structure).

## Reader
French-speaking expatriates and investors in Spain, mainly around Valencia; Belgian and Swiss
francophones as a secondary audience. FR brings **47% of all form enquiries**, so it's the first
locale for any campaign.

## Rules
- Sentence case for headings and titles (no Title Case), never `text-transform: uppercase`.
- **Headings in noun form**: « Obtention du NIE », « Dépôt de la demande ». The H1 keeps the focus
  keyword. If that keyword is a verb phrase, flag it to Mike.
- Banned: « Découvrez », « Ce guide », « Chez Delaguía y Luzón », « il est important de »,
  « dans le cadre de », « Conclusion » as a heading, « consultation gratuite » /
  « Première consultation gratuite » (still in the single-post template sidebar, a Mike task),
  « 65 ans d'expérience ».
- « Les points essentiels » is always an `<h2>`, never a `<p>`.
- One idea per paragraph, 3 or 4 sentences max.
- French typography: non-breaking space before « : ; ? ! » and inside « guillemets ». Write
  amounts as `1 221 €`.
- Use the Spanish name of a procedure, then a French explanation at first mention: « le NIE
  (numéro d'identification d'étranger) ».
- Meta description ≤ 155 characters.
- Forbidden sources still linked: post 3013 (garrigues.com), post 4413 (jacheteenespagne.com).
- Post-body article styling (historic): H2 accent `#007BB3`, text `#1a3a4a`, callout gradient
  `#eaf4fb→#ddeef8` with a `#007BB3` left border. Don't restyle existing posts just for this.
